# 后端技术文档

## 1. 认证相关接口

### 1.1 发送注册验证码
- **接口路径**: `/api/auth/send-register-code`
- **请求方法**: POST
- **功能描述**: 发送注册验证码到用户邮箱
- **请求参数**:
  - email: string (用户邮箱)
- **响应格式**:
  ```json
  {
    "message": "验证码发送成功"
  }
  ```
- **状态码**:
  - 200: 成功
  - 400: 邮箱已被注册

### 1.2 发送重置密码验证码
- **接口路径**: `/api/auth/send-reset-code`
- **请求方法**: POST
- **功能描述**: 发送重置密码验证码到用户邮箱
- **请求参数**:
  - username: string (用户名)
  - email: string (用户邮箱)
- **响应格式**:
  ```json
  {
    "message": "验证码发送成功"
  }
  ```
- **状态码**:
  - 200: 成功
  - 400: 用户不存在或邮箱不匹配

### 1.3 登录
- **接口路径**: `/api/auth/login`
- **请求方法**: POST
- **功能描述**: 用户登录，返回JWT令牌
- **请求参数**:
  - username: string (用户名)
  - password: string (密码)
- **响应格式**:
  ```json
  {
    "access_token": "string",
    "token_type": "bearer",
    "user": {
      "id": "string",
      "username": "string",
      "email": "string",
      "is_active": true,
      "role": "string",
      "created_at": "string",
      "updated_at": "string"
    }
  }
  ```
- **状态码**:
  - 200: 成功
  - 401: 用户名或密码错误，或用户账号已被禁用
  - 422: 缺少用户名或密码

### 1.4 注册
- **接口路径**: `/api/auth/register`
- **请求方法**: POST
- **功能描述**: 用户注册
- **请求参数**:
  - username: string (用户名)
  - email: string (邮箱)
  - password: string (密码)
  - code: string (验证码)
  - role: string (角色)
- **响应格式**:
  ```json
  {
    "id": "string",
    "username": "string",
    "email": "string",
    "is_active": true,
    "role": "string",
    "created_at": "string",
    "updated_at": "string"
  }
  ```
- **状态码**:
  - 201: 成功创建
  - 400: 用户名已存在，邮箱已被注册，验证码错误或过期

### 1.5 重置密码
- **接口路径**: `/api/auth/reset-password`
- **请求方法**: POST
- **功能描述**: 重置用户密码
- **请求参数**:
  - username: string (用户名)
  - email: string (邮箱)
  - code: string (验证码)
  - new_password: string (新密码)
- **响应格式**:
  ```json
  {
    "message": "密码重置成功"
  }
  ```
- **状态码**:
  - 200: 成功
  - 400: 用户不存在，邮箱不匹配，验证码错误或过期，新密码与旧密码相同
  - 404: 用户不存在

### 1.6 验证令牌
- **接口路径**: `/api/auth/verify`
- **请求方法**: GET
- **功能描述**: 验证JWT令牌是否有效
- **请求参数**: 无（需要在请求头中携带Authorization: Bearer <token>）
- **响应格式**:
  ```json
  {
    "valid": true,
    "user": {
      "id": "string",
      "username": "string",
      "email": "string",
      "is_active": true,
      "role": "string",
      "created_at": "string",
      "updated_at": "string"
    }
  }
  ```
- **状态码**:
  - 200: 成功

### 1.7 获取当前用户信息
- **接口路径**: `/api/users/me`
- **请求方法**: GET
- **功能描述**: 获取当前登录用户的信息

  }

- **状态码**:
  - 200: 成功
  - 401: 令牌无效或已过期，用户不存在，用户账号已被禁用

### 1.8 更新当前用户信息

- **功能描述**: 暂停对话测试流程
- **请求参数**:
  - session_id: string (对话会话ID)
- **响应格式**:
  ```json
  {
    "status": "success",
    "message": "测试已成功暂停",
    "data": {
      "session_id": "string",
      "status": "paused",
      "pause_time": "string"
    }
  }
  ```
- **状态码**:
  - 200: 成功
  - 400: session_id 不能为空，会话未处于测试状态
  - 404: 会话不存在
  - 500: 暂停测试失败

### 5.7 创建会话

  - 200: 成功
  - 400: 会话类型不能为空
  - 500: 创建会话失败

### 5.8 保存对话历史
- **接口路径**: `/api/dialogue/save-history`
- **请求方法**: POST
- **功能描述**: 保存对话历史到数据库
- **请求参数**:
  - session_id: string (会话ID，可选)
  - patient_id: string (患者ID，可选)
  - title: string (对话标题)
  - user_id: string (用户ID)
- **响应格式**:
  ```json
  {
    "status": "success",
    "message": "对话历史保存成功",
    "data": {
      "conversation_id": "string",
      "message_count": 0
    }
  }
  ```
- **状态码**:
  - 200: 成功
  - 400: session_id或patient_id至少需要提供一个，对话历史为空
  - 404: 对话历史不存在
  - 500: 保存对话历史失败
