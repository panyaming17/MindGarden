## 🎯 核心功能模块

### 1. 多智能体系统 (backend/agents/)

**职责**: 实现六阶段心理疏导流程

| 智能体 | 文件 | 职责 |
|--------|------|------|
| 记录师 | `recorder_agent.py` | 记录对话、预测四维情绪、判断阶段 |
| 分析师 | `analyst_agent.py` | 分析核心话题、识别思维陷阱 |
| 疏导师 | `therapist_agent.py` | 生成疏导回应、干预方案 |

**工作流程**:
```
用户对话 → 记录师 → 阶段判断 → 分析师（可选） → 疏导师 → 回应
           ↓
       情绪预测
```

### 2. API 路由层 (backend/api/)

**职责**: 提供 RESTful API 接口

| 端点 | 功能 |
|------|------|
| `auth_endpoints.py` | 用户认证（登录、注册） |
| `conversation_endpoints.py` | 对话管理（创建、查询） |
| `dialogue_endpoints.py` | 对话历史（保存、检索） |
| `recorder_endpoints.py` | 记录师接口 |
| `analyst_endpoints.py` | 分析师接口 |
| `therapist_endpoints.py` | 疏导师接口 |
| `rule_endpoints.py` | 规则管理（TCM 规则） |
| `admin_endpoints.py` | 管理员接口 |

### 3. 业务服务层 (backend/services/)

**职责**: 实现核心业务逻辑

| 服务 | 功能 |
|------|------|
| `alert_service.py` | 风险预警生成和管理 |
| `alert_scheduler.py` | 定时提醒调度 |
| `emotion_rag_service.py` | 情绪 RAG 检索 |
| `clinical_case_rag.py` | 临床案例检索 |
| `analysis_service.py` | 情绪分析和报告生成 |

### 4. 前端组件 (frontend/src/components/)

## 🚀 启动方式

### 开发环境

**Windows (PowerShell)**:
```powershell
cd project
.\start-dev.ps1
```

**手动启动**:

1. **后端**:
```bash
cd backend
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload
```

2. **前端**:
```bash
cd frontend
npm install
npm run dev
```
