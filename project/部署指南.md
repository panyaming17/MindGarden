# 部署指南

## 生产环境部署完整步骤

### 一、服务器环境准备

#### 1. 安装系统依赖

```bash
# Ubuntu/Debian
sudo apt update
sudo apt install -y python3.9 python3-pip python3-venv
sudo apt install -y nodejs npm
sudo apt install -y mysql-server
sudo apt install -y nginx
sudo apt install -y git

# CentOS/RHEL
sudo yum install -y python3.9 python3-pip
sudo yum install -y nodejs npm
sudo yum install -y mysql-server
sudo yum install -y nginx
sudo yum install -y git
```

#### 2. 配置 MySQL 数据库

```bash
# 启动 MySQL
sudo systemctl start mysql
sudo systemctl enable mysql

# 安全初始化
sudo mysql_secure_installation

# 登录 MySQL 创建数据库
mysql -u root -p

# 执行 SQL 命令
CREATE DATABASE emotional_coaching_system_db 
CHARACTER SET utf8mb4 
COLLATE utf8mb4_unicode_ci;

CREATE USER 'emotional_user'@'localhost' IDENTIFIED BY 'your_secure_password';
GRANT ALL PRIVILEGES ON emotional_coaching_system_db.* TO 'emotional_user'@'localhost';
FLUSH PRIVILEGES;
EXIT;
```

### 二、后端部署

#### 1. 克隆项目并安装依赖

```bash
cd /var/www
git clone <repository-url> emotional-coaching
cd emotional-coaching/backend

# 创建虚拟环境
python3 -m venv venv
source venv/bin/activate

# 安装依赖
pip install -r requirements.txt
```

#### 2. 配置环境变量

```bash
cd /var/www/emotional-coaching
cp .env.example .env

# 编辑 .env 文件
nano .env
```

**重要配置项：**
```ini
# 生产环境必须修改
DEBUG=False
LLM_PROVIDER=alibaba_bailian
ALIBABA_BAILIAN_API_KEY=your-actual-api-key
DB_HOST=localhost
DB_USER=emotional_user
DB_PASSWORD=your_secure_password
DB_NAME=emotional_coaching_system_db
API_HOST=0.0.0.0
API_PORT=8000
```

#### 3. 数据库初始化

```bash
# 激活虚拟环境
source venv/bin/activate

# 运行初始化脚本（如有）
python scripts/init_database.py
```

#### 4. 创建 Systemd 服务

```bash
sudo nano /etc/systemd/system/emotional-backend.service
```

**服务配置：**
```ini
[Unit]
Description=Emotional Coaching Backend API
After=network.target mysql.service

[Service]
Type=notify
User=www-data
Group=www-data
WorkingDirectory=/var/www/emotional-coaching/backend
Environment="PATH=/var/www/emotional-coaching/backend/venv/bin"
ExecStart=/var/www/emotional-coaching/backend/venv/bin/uvicorn main:app --host 0.0.0.0 --port 8000
Restart=always
RestartSec=10

# 安全设置
NoNewPrivileges=true
PrivateTmp=true

[Install]
WantedBy=multi-user.target
```

**启动服务：**
```bash
sudo systemctl daemon-reload
sudo systemctl start emotional-backend
sudo systemctl enable emotional-backend
sudo systemctl status emotional-backend
```

### 三、前端部署

#### 1. 构建生产版本

```bash
cd /var/www/emotional-coaching/frontend

# 安装依赖
npm install

# 配置环境变量
cp .env.example .env
nano .env

# 修改 API 地址为生产环境地址
VITE_API_BASE_URL=https://your-domain.com/api

# 构建
npm run build
```

#### 2. Nginx 配置

```bash
sudo nano /etc/nginx/sites-available/emotional-coaching
```

**Nginx 配置：**
```nginx
server {
    listen 80;
    server_name your-domain.com;
    
    # 前端静态文件
    root /var/www/emotional-coaching/frontend/dist;
    index index.html;
    
    # 前端路由
    location / {
        try_files $uri $uri/ /index.html;
    }
    
    # API 反向代理
    location /api/ {
        proxy_pass http://localhost:8000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
    }
    
    # 静态资源缓存
    location ~* \.(jpg|jpeg|png|gif|ico|css|js)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }
    
    # 禁止访问隐藏文件
    location ~ /\. {
        deny all;
    }
}
```

**启用配置：**
```bash
sudo ln -s /etc/nginx/sites-available/emotional-coaching /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl restart nginx
sudo systemctl enable nginx
```

#### 3. 配置 HTTPS（推荐）

```bash
# 安装 Certbot
sudo apt install -y certbot python3-certbot-nginx

# 获取证书
sudo certbot --nginx -d your-domain.com

# 自动续期
sudo crontab -e
# 添加：0 3 * * * certbot renew --quiet
```

### 五、监控和维护

#### 1. 日志管理

```bash
# 后端日志
sudo journalctl -u emotional-backend -f

# Nginx 日志
sudo tail -f /var/log/nginx/access.log
sudo tail -f /var/log/nginx/error.log

# 日志轮转配置
sudo nano /etc/logrotate.d/emotional-coaching
```

#### 2. 备份策略

```bash
# 数据库备份脚本
sudo nano /usr/local/bin/backup-emotional-db.sh
```

**备份脚本：**
```bash
#!/bin/bash
DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_DIR="/var/backups/emotional"
mkdir -p $BACKUP_DIR

mysqldump -u emotional_user -p'your_password' \
  emotional_coaching_system_db > \
  $BACKUP_DIR/db_backup_$DATE.sql

# 保留最近 30 天的备份
find $BACKUP_DIR -name "db_backup_*.sql" -mtime +30 -delete
```

**设置定时任务：**
```bash
sudo crontab -e
# 每天凌晨 2 点备份
0 2 * * * /usr/local/bin/backup-emotional-db.sh
```

```bash
htop

```

### 六、故障排查

#### 常见问题

**1. 后端服务无法启动**
```bash
# 查看详细错误
sudo journalctl -u emotional-backend -n 50

# 检查端口占用
sudo lsof -i :8000

# 检查数据库连接
mysql -u emotional_user -p -e "SELECT 1"
```

**2. 前端页面无法访问**
```bash
# 检查 Nginx 配置
sudo nginx -t

# 检查文件权限
sudo chown -R www-data:www-data /var/www/emotional-coaching/frontend/dist
```

**3. API 请求失败**
```bash
# 检查后端日志
sudo journalctl -u emotional-backend -f

# 测试 API 直连
curl http://localhost:8000/api/health
```

### 七、安全加固

#### 1. 防火墙配置

```bash
# 配置 UFW 防火墙
sudo ufw allow 22/tcp    # SSH
sudo ufw allow 80/tcp    # HTTP
sudo ufw allow 443/tcp   # HTTPS
sudo ufw enable
```

#### 2. 数据库安全

```sql
-- 限制数据库用户权限
REVOKE FILE ON *.* FROM 'emotional_user'@'localhost';
REVOKE GRANT OPTION ON *.* FROM 'emotional_user'@'localhost';
```

#### 3. 定期更新

```bash
# 定期更新系统包
sudo apt update && sudo apt upgrade -y

# 定期更新 Python 依赖
source venv/bin/activate
pip install --upgrade -r requirements.txt

# 定期更新 Node.js 依赖
cd frontend
npm update
```

## 快速部署脚本

可以使用以下脚本一键部署：

```bash
#!/bin/bash
# deploy.sh

set -e

echo "开始部署..."

# 1. 安装依赖
sudo apt update
sudo apt install -y python3-pip python3-venv nodejs npm mysql-server nginx

# 2. 配置数据库
sudo systemctl start mysql
mysql -u root -e "CREATE DATABASE IF NOT EXISTS emotional_coaching_system_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

# 3. 安装后端
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# 4. 构建前端
cd ../frontend
npm install
npm run build

# 5. 配置 Nginx
sudo cp ../nginx.conf /etc/nginx/sites-available/emotional-coaching
sudo ln -s /etc/nginx/sites-available/emotional-coaching /etc/nginx/sites-enabled/

# 6. 启动服务
sudo systemctl restart nginx

echo "部署完成！"
```
