# 后端技术文档

## 1. 概述

本文档描述了支持前端登录、注册、重置密码功能的后端系统设计。后端系统需要提供用户认证、用户管理等功能，确保用户数据的安全性和可靠性。

## 2. 技术栈

- **语言**：Python 3.9+
- **框架**：FastAPI
- **数据库**：PostgreSQL
- **缓存**：Redis（用于存储验证码）
- **认证**：JWT (JSON Web Token)
- **密码加密**：bcrypt
- **邮件服务**：SMTP或第三方邮件服务
- **CORS**：支持跨域请求

## 4. API 接口设计

### 4.1 认证相关接口

#### 4.1.1 登录

- **路径**：`POST /api/v1/auth/login`
- **描述**：用户登录，返回JWT令牌
- **请求体**：
  ```json
  {
    "username": "string",
    "password": "string"
  }
  ```
- **响应**：
  - 成功 (200 OK):
    ```json
    {
      "access_token": "string",
      "token_type": "bearer",
      "user": {
        "id": 1,
        "username": "string",
        "email": "string"
      }
    }
    ```
  - 失败 (401 Unauthorized):
    ```json
    {
      "detail": "用户名或密码错误"
    }
    ```

#### 4.1.2 发送注册验证码

- **路径**：`POST /api/auth/send-register-code`
- **描述**：发送注册验证码到用户邮箱
- **请求体**：
  ```json

  }
  ```
- **响应**：
  - 成功 (200 OK): 无返回数据
  - 失败 (400 Bad Request):
    ```json
    {
      "detail": "邮箱已被注册"
    }
    ```

## 5. 认证流程

### 5.1 登录流程

1. 前端发送登录请求，包含用户名和密码
2. 后端验证用户名和密码：
   - 检查用户名是否存在
   - 使用bcrypt验证密码
3. 验证成功：
   - 生成JWT令牌
   - 将令牌存储在会话表中
   - 返回令牌和用户信息
4. 验证失败：
   - 返回401错误

### 5.2 注册流程

1. 前端发送获取验证码请求，包含邮箱
2. 后端验证邮箱：
   - 检查邮箱是否已被注册
   - 生成6位数字验证码
   - 将验证码存储到Redis（过期时间5-10分钟）
   - 发送验证码到用户邮箱
3. 前端发送注册请求，包含用户名、邮箱、验证码和密码
4. 后端验证请求数据：
   - 检查用户名是否已存在
   - 检查邮箱是否已存在
   - 验证验证码是否正确且未过期
   - 验证密码强度
5. 验证通过：
   - 使用bcrypt加密密码
   - 创建新用户
   - 返回用户信息
6. 验证失败：
   - 返回400错误（验证码错误或已过期、用户名或邮箱已存在）

### 5.3 重置密码流程

1. 前端发送获取验证码请求，包含用户名和邮箱
2. 后端验证用户名和邮箱：
   - 检查用户名是否存在
   - 检查邮箱是否与用户名关联
   - 生成6位数字验证码
   - 将验证码存储到Redis（过期时间5-10分钟）
   - 发送验证码到用户邮箱
3. 前端发送重置密码请求，包含用户名、邮箱、验证码和新密码
4. 后端验证请求数据：
   - 检查用户名是否存在
   - 检查邮箱是否与用户名关联
   - 验证验证码是否正确且未过期
   - 验证新密码强度
5. 验证通过：
   - 使用bcrypt加密新密码
   - 更新用户密码
   - 返回成功消息
6. 验证失败：
   - 返回404错误（用户不存在）
   - 返回400错误（验证码错误或已过期）

## 6. 安全性考虑

### 6.1 密码安全

- 使用bcrypt算法加密密码，设置适当的工作因子
- 密码长度至少为6位，建议包含大小写字母、数字和特殊字符
- 密码加密过程在服务器端进行，不在前端处理

### 6.2 认证安全

- 使用JWT令牌进行认证，设置合理的过期时间
- 令牌存储在会话表中，支持令牌撤销
- 敏感操作需要重新验证用户身份

### 6.3 数据安全

- 传输过程中使用HTTPS加密
- 数据库连接使用参数化查询，防止SQL注入
- 输入数据进行严格验证，防止XSS攻击
- 敏感信息（如密码）不在日志中记录

### 6.4 速率限制

- 对登录、注册接口实施速率限制，防止暴力破解
- 对同一IP地址的请求频率进行限制
- 对发送验证码接口实施速率限制（如每分钟最多1次）
- 对验证码错误次数进行限制（如连续5次错误后锁定一段时间）

### 6.5 邮箱验证安全

- 使用Redis存储验证码，设置合理的过期时间（5-10分钟）
- 验证码长度为6位数字，降低被猜测的概率
- 邮件内容包含验证码、有效期、操作提示
- 邮件内容包含安全提醒（如不要分享验证码）
- 发送验证码时检查邮箱格式的有效性

## 8. 前端集成

### 8.1 认证状态管理

前端可以使用以下方式管理认证状态：

1. 将JWT令牌存储在localStorage中
2. 使用axios拦截器自动添加认证头
3. 实现令牌过期处理逻辑

### 8.2 错误处理

前端需要处理以下错误情况：

1. 401错误：令牌无效或已过期，需要重新登录
2. 400错误：请求参数错误，需要提示用户
   - 验证码错误或已过期
   - 用户名或邮箱已存在
3. 404错误：资源不存在，需要提示用户
   - 用户不存在
   - 用户名或邮箱错误
4. 500错误：服务器内部错误，需要提示用户

### 8.3 邮箱验证集成

前端需要实现以下邮箱验证功能：

1. 注册流程：
   - 输入邮箱后，点击发送验证码按钮
   - 显示60秒倒计时，防止重复发送
   - 输入验证码后，提交注册请求

2. 重置密码流程：
   - 输入用户名和邮箱后，点击发送验证码按钮
   - 显示60秒倒计时，防止重复发送
   - 输入验证码和新密码后，提交重置密码请求

3. 验证码验证：
   - 实时验证验证码格式（6位数字）
   - 提交前验证所有字段
   - 显示清晰的错误提示信息

```python
from fastapi import APIRouter, Depends, HTTPException
from sqlalchemy.orm import Session
from fastapi.security import OAuth2PasswordBearer, OAuth2PasswordRequestForm
from jose import JWTError, jwt
from passlib.context import CryptContext

from app.db.database import get_db
from app.models.user import User
from app.schemas.auth import Token, TokenData, UserInDB

router = APIRouter(prefix="/api/auth", tags=["auth"])
pwd_context = CryptContext(schemes=["bcrypt"], deprecated="auto")
oauth2_scheme = OAuth2PasswordBearer(tokenUrl="/api/auth/login")

# 验证密码
def verify_password(plain_password, hashed_password):
    return pwd_context.verify(plain_password, hashed_password)

# 获取用户
def get_user(db, username: str):
    return db.query(User).filter(User.username == username).first()

# 创建访问令牌
def create_access_token(data: dict):
    to_encode = data.copy()
    encoded_jwt = jwt.encode(to_encode, SECRET_KEY, algorithm=ALGORITHM)
    return encoded_jwt

# 登录接口
@router.post("/login", response_model=Token)
async def login(form_data: OAuth2PasswordRequestForm = Depends(), db: Session = Depends(get_db)):
    user = get_user(db, form_data.username)
    if not user or not verify_password(form_data.password, user.password_hash):
        raise HTTPException(status_code=401, detail="用户名或密码错误")
    access_token = create_access_token(data={"sub": user.username})
    return {
        "access_token": access_token,
        "token_type": "bearer",
        "user": {
            "id": user.id,
            "username": user.username,
            "email": user.email
        }
    }
```

#### 10.3.2 注册接口示例

```python
from fastapi import APIRouter, Depends, HTTPException
from sqlalchemy.orm import Session

from app.db.database import get_db
from app.models.user import User
from app.schemas.user import UserCreate, User as UserSchema
from app.utils.security import get_password_hash

router = APIRouter(prefix="/api/auth", tags=["auth"])

# 注册接口
@router.post("/register", response_model=UserSchema, status_code=201)
async def register(user: UserCreate, db: Session = Depends(get_db)):
    # 检查用户名是否已存在
    db_user = db.query(User).filter(User.username == user.username).first()
    if db_user:
        raise HTTPException(status_code=400, detail="用户名已存在")
    
    # 检查邮箱是否已存在
    db_user = db.query(User).filter(User.email == user.email).first()
    if db_user:
        raise HTTPException(status_code=400, detail="邮箱已被使用")
    
    # 创建新用户
    hashed_password = get_password_hash(user.password)
    db_user = User(
        username=user.username,
        email=user.email,
        password_hash=hashed_password
    )
    db.add(db_user)
    db.commit()
    db.refresh(db_user)
    
    return db_user
```

```python
router = APIRouter(prefix="/api/auth", tags=["auth"])

# 重置密码接口
@router.post("/reset-password")
async def reset_password(reset_data: ResetPassword, db: Session = Depends(get_db)):
    # 检查用户名是否存在
    user = db.query(User).filter(User.username == reset_data.username).first()
    if not user:
        raise HTTPException(status_code=404, detail="用户不存在")
    
    # 更新密码
    hashed_password = get_password_hash(reset_data.new_password)
    user.password_hash = hashed_password
    db.commit()
    
    return {"message": "密码重置成功"}
```
